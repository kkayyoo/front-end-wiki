# 百度前端 Agent 面试题（2026-06-06）

## 来源
- 面试公司：百度
- 面试岗位：前端 Agent 方向
- 面试日期：约 2026 年上半年

## 原始题目（用户整理）

> 注：前期有部分零碎问题因紧张未记全

3. 日常开发过程中如何使用 AI
4. 项目里如何做测试，面试官顺着问题深挖自动化工作流相关内容
5. 【追问】手动让 AI 编写测试脚本比较麻烦，如果已有现成 Skill 该如何使用
6. 【追问】怎样保证 Skill 能够稳定执行，在面试官引导下答出固定 workflow 主流程、细分节点交给 Agent/LLM 处理
7. 【追问】workflow 具体怎么落地使用，本人回答不出，面试官提示可以把 workflow 配置写入 system prompt
8. 使用各类 AI 工具至今一共花费多少钱（本人零花费，就此闲聊）
9. 项目里打字机文字效果的实现方式
10. 打字机动画帧率数值以及帧率计算逻辑
11. markdown 渲染如何做安全防护、如何防范 XSS（用户回答：GFM 白名单方案）
12. CSRF 相关攻击知识
13. AI 流式输出选用 SSE 而不选用 WebSocket 的原因
14. AI 生成歌曲耗时久，怎么优化用户等待体验
15. 歌曲生成进度条实时任务更新的实现（用户回答：SSE 自定义事件）
16. 音频播放器采用全局状态管理的原因
17. 根据音频实现音波震动效果的实现思路（用户回答：现成音频库、定时解析音频主频+噪声模拟小波；面试官补充：音频文件可解析为携带频谱信息的数组）
18. 项目选用 Next.js 的原因（用户吐槽 SSR 缺陷、无法使用浏览器 API；面试官点明高交互场景不适合 SSR，属于选型问题）
19. 了解哪些前端性能指标、对应的性能监控手段
20. 结合项目讲解前端性能优化方案（面试官表示是加分项，很少求职者深耕这块）
21. AI 未来会不会取代前端开发
22. 自身偏爱美学设计，了解哪些动画库、UI 组件库

## 题目分类归档

### AI 开发 & Agent 工作流（Q3–Q8，Q21）
- AI 辅助开发日常使用方式
- Skill 复用机制
- Workflow 稳定执行：固定主流程 + LLM 细分节点
- Workflow 落地：写入 system prompt

### 渲染与动画（Q9–Q10，Q17，Q22）
- 打字机效果实现（requestAnimationFrame / setTimeout）

- 音波震动效果（Web Audio API + 频谱数组解析）
- 动画库 / UI 组件库偏好

### 安全（Q11–Q12）
- Markdown XSS 防护：GFM 白名单（DOMPurify + marked）
- CSRF 攻击与防御

### SSE & 实时通信（Q13–Q15）
- SSE vs WebSocket 选型分析
- SSE 自定义事件实现进度条

### 音频 & 全局状态（Q16–Q17）
- 音频播放器全局状态管理原因
- Web Audio API 频谱解析

### 性能优化（Q19–Q20）
- 前端性能指标（Core Web Vitals: LCP/FID/CLS）
- 监控手段（Lighthouse/PerformanceObserver/RUM）
- 项目级性能优化落地方案

### 框架选型（Q18）

- 高交互场景的框架选型建议

### 用户体验 & 等待优化（Q14）
