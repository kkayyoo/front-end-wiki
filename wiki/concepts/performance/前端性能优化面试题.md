# 前端性能优化面试题

## 1. Core Web Vitals

### 指标说明

| 指标 | 全称 | 含义 | 目标值 |
|------|------|------|--------|
| **LCP** | Largest Contentful Paint | 主要内容加载时间 | < 2.5s |
| **CLS** | Cumulative Layout Shift | 视觉稳定性（累计布局偏移） | < 0.1 |
| **INP** | Interaction to Next Paint | 交互响应时间（取代 FID） | < 200ms |
| **FID** | First Input Delay | 首次输入延迟（已被 INP 取代） | < 100ms |

> **注意**：Google 于 2024 年 3 月正式用 INP 替代 FID 作为 Core Web Vitals 指标之一。

### 优化方向

**LCP 优化：**
- 优化图片（WebP/AVIF 格式、lazy loading、srcset）
- 减少服务器响应时间（CDN、缓存）
- 预加载关键资源 `<link rel="preload">`
- 避免阻塞渲染的 JS/CSS

**CLS 优化：**
- 为图片/视频预留尺寸（`width`/`height` 属性或 `aspect-ratio`）
- 避免动态注入内容（广告、GDPR 提示）
- 使用 CSS `transform` 代替改变 `top/left` 的动画

**INP 优化：**
- 减少主线程阻塞（代码分割、Web Workers）
- 拆分长任务（Long Tasks > 50ms）
- 避免同步布局强制（强制回流）

### 面试问答

**Q: 如何诊断并改善一个慢页面？**

> "首先用 Lighthouse 建立基线指标（LCP/CLS/INP/Bundle Size）。如果 LCP 慢，优先优化图片（WebP、lazy loading）并检查是否有阻塞渲染的资源。如果 INP 高，用 Chrome DevTools Performance tab 找长任务，通过代码分割和 Web Worker 卸载计算。CLS 问题通常源于没有预留空间的动态内容，加 `aspect-ratio` 或固定尺寸解决。最后在模拟 3G 网络下再次测量，确认改善效果。"

## 2. 代码分割（Code Splitting）与懒加载

### 核心概念

代码分割将大 bundle 拆分成按需加载的小块，减少初始加载体积。

### React 懒加载实现

```typescript
import React, { Suspense, lazy } from 'react';

// 懒加载组件（动态 import）
const Dashboard = lazy(() => import('./Dashboard'));
const DataTable = lazy(() => import('./DataTable'));

// 路由级别的代码分割
const AppRouter: React.FC = () => {
  return (
    <Suspense fallback={<LoadingSpinner />}>
      <Routes>
        <Route path="/dashboard" element={<Dashboard />} />
        <Route path="/data" element={<DataTable />} />
      </Routes>
    </Suspense>
  );
};
```

### 动态 Import（非组件场景）

```typescript
// 按需加载重型库（如 Chart.js）
async function loadChart(data: ChartData[]) {
  const { Chart } = await import('chart.js');
  return new Chart(canvas, { data });
}

// Azure Data Copy: 按需加载大型数据处理工具
async function exportToExcel(rows: DataRow[]) {
  const { utils, writeFile } = await import('xlsx');
  const ws = utils.json_to_sheet(rows);
  const wb = utils.book_new();
  utils.book_append_sheet(wb, ws, 'Data');
  writeFile(wb, 'export.xlsx');
}
```

### Angular 懒加载路由（实际项目经验）

```typescript
// app-routing.module.ts
const routes: Routes = [
  {
    path: 'copy-jobs',
    loadChildren: () =>
      import('./features/copy-jobs/copy-jobs.module').then(m => m.CopyJobsModule),
  },
  {
    path: 'analytics',
    loadChildren: () =>
      import('./features/analytics/analytics.module').then(m => m.AnalyticsModule),
  },
];
```

### 面试问答

**Q: 代码分割的 trade-off 是什么？**

> "代码分割减少初始 bundle，但增加网络请求次数。需要权衡：对高频访问的页面可以 prefetch（`import(/* webpackPrefetch: true */ './module')`），对低频页面才完全按需加载。Suspense fallback 的体验也很重要，避免太频繁的 loading 状态。"

## 3. 图片优化

### 格式选择

| 格式 | 压缩率 | 兼容性 | 适用场景 |
|------|--------|--------|----------|
| WebP | 比 JPEG 小 25-30% | 现代浏览器 | 通用 |
| AVIF | 比 JPEG 小 50% | Chrome 85+, Firefox 93+ | 高压缩需求 |
| JPEG | 基准 | 全浏览器 | 降级 fallback |
| SVG | - | 全浏览器 | 图标、矢量图 |

### `<picture>` 元素 + srcset

```html
<picture>
  <!-- AVIF: 最佳压缩 -->
  <source srcset="hero-800.avif 800w, hero-1200.avif 1200w" type="image/avif" />
  <!-- WebP: 广泛支持 -->
  <source srcset="hero-800.webp 800w, hero-1200.webp 1200w" type="image/webp" />
  <!-- JPEG fallback -->
  <img
    src="hero-800.jpg"
    srcset="hero-800.jpg 800w, hero-1200.jpg 1200w"
    sizes="(max-width: 768px) 100vw, 50vw"
    loading="lazy"
    width="800"
    height="450"
    alt="Hero image"
  />
</picture>
```

### React 图片懒加载组件

```typescript
interface LazyImageProps {
  src: string;
  alt: string;
  width: number;
  height: number;
  placeholder?: string;
}

const LazyImage: React.FC<LazyImageProps> = ({
  src,
  alt,
  width,
  height,
  placeholder = 'data:image/gif;base64,R0lGODlhAQABAAD/ACwAAAAAAQABAAACADs=',
}) => {
  const [loaded, setLoaded] = React.useState(false);
  const imgRef = React.useRef<HTMLImageElement>(null);

  React.useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting && imgRef.current) {
          imgRef.current.src = src;
          observer.disconnect();
        }
      },
      { rootMargin: '200px' } // 提前 200px 开始加载
    );
    if (imgRef.current) observer.observe(imgRef.current);
    return () => observer.disconnect();
  }, [src]);

  return (
    <img
      ref={imgRef}
      src={placeholder}
      alt={alt}
      width={width}
      height={height}
      onLoad={() => setLoaded(true)}
      style={{ opacity: loaded ? 1 : 0, transition: 'opacity 0.3s' }}
    />
  );
};
```

## 4. JavaScript 性能优化

### 减少重排（Reflow）与重绘（Repaint）

```typescript
// ❌ 坏：多次触发重排
function badLayout(elements: HTMLElement[]) {
  elements.forEach(el => {
    const height = el.offsetHeight; // 读取，触发 reflow
    el.style.height = height + 10 + 'px'; // 写入，触发 reflow
  });
}

// ✅ 好：批量读写，使用 requestAnimationFrame
function goodLayout(elements: HTMLElement[]) {
  // 批量读取
  const heights = elements.map(el => el.offsetHeight);
  
  // 批量写入（下一帧）
  requestAnimationFrame(() => {
    elements.forEach((el, i) => {
      el.style.height = heights[i] + 10 + 'px';
    });
  });
}

// ✅ 更好：用 CSS transform 替代 position 动画（不触发 reflow）
// Bad:  element.style.left = x + 'px';
// Good: element.style.transform = `translateX(${x}px)`;
```

### 防抖与节流

```typescript
// 防抖：连续输入，只在停止后执行（搜索框）
function debounce<T extends (...args: unknown[]) => unknown>(
  fn: T,
  delay: number
): (...args: Parameters<T>) => void {
  let timer: ReturnType<typeof setTimeout>;
  return (...args: Parameters<T>) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

// 节流：持续触发，按频率执行（scroll/resize）
function throttle<T extends (...args: unknown[]) => unknown>(
  fn: T,
  interval: number
): (...args: Parameters<T>) => void {
  let lastTime = 0;
  return (...args: Parameters<T>) => {
    const now = Date.now();
    if (now - lastTime >= interval) {
      lastTime = now;
      fn(...args);
    }
  };
}

// 使用
const handleSearch = debounce((query: string) => fetchResults(query), 300);
const handleScroll = throttle(() => updateScrollPosition(), 16); // ~60fps
```

### Web Workers（卸载主线程计算）

```typescript
// worker.ts
self.addEventListener('message', (e: MessageEvent<{ data: number[] }>) => {
  const { data } = e.data;
  // 在 Worker 线程中执行耗时计算
  const result = data.reduce((sum, n) => sum + n * n, 0);
  self.postMessage({ result });
});

// main.ts - Azure Data Copy: 大数据集聚合计算
class DataAggregationWorker {
  private worker: Worker;

  constructor() {
    this.worker = new Worker(new URL('./worker.ts', import.meta.url));
  }

  aggregate(data: number[]): Promise<number> {
    return new Promise((resolve, reject) => {
      this.worker.postMessage({ data });
      this.worker.onmessage = (e) => resolve(e.data.result);
      this.worker.onerror = reject;
    });
  }

  terminate() {
    this.worker.terminate();
  }
}
```

## 5. React 渲染性能优化

### memo、useMemo、useCallback

```typescript
interface DataRowProps {
  row: DataRecord;
  onSelect: (id: string) => void;
}

// React.memo：避免父组件重渲染导致子组件不必要渲染
const DataRow = React.memo<DataRowProps>(({ row, onSelect }) => {
  return (
    <tr onClick={() => onSelect(row.id)}>
      <td>{row.name}</td>
      <td>{row.value}</td>
    </tr>
  );
}, (prevProps, nextProps) => {
  // 自定义比较：只有 id 或 value 变化才重渲染
  return prevProps.row.id === nextProps.row.id &&
         prevProps.row.value === nextProps.row.value;
});

// 父组件
const DataTable: React.FC<{ data: DataRecord[] }> = ({ data }) => {
  // useMemo：缓存昂贵计算结果
  const sortedData = useMemo(
    () => [...data].sort((a, b) => a.name.localeCompare(b.name)),
    [data]
  );

  // useCallback：稳定函数引用，配合 React.memo 使用
  const handleSelect = useCallback((id: string) => {
    console.log('Selected:', id);
  }, []); // 空依赖：函数永不变化

  return (
    <table>
      {sortedData.map(row => (
        <DataRow key={row.id} row={row} onSelect={handleSelect} />
      ))}
    </table>
  );
};
```

> ⚠️ **面试注意**：useMemo/useCallback 有开销（闭包 + 依赖比较），**先 Profile，再优化**，不要过度使用。

### 虚拟滚动（Virtualization）

虚拟滚动只渲染可视区域内的行，适用于大数据表格（Azure Data Copy 的核心场景）。

```typescript
import { FixedSizeList as List } from 'react-window';

interface VirtualTableProps {
  data: DataRecord[];
  height: number;
}

const ROW_HEIGHT = 48;

const VirtualTable: React.FC<VirtualTableProps> = ({ data, height }) => {
  const Row = ({ index, style }: { index: number; style: React.CSSProperties }) => (
    <div style={style} className="table-row">
      <span>{data[index].name}</span>
      <span>{data[index].value}</span>
      <span>{data[index].status}</span>
    </div>
  );

  return (
    <List
      height={height}
      itemCount={data.length}
      itemSize={ROW_HEIGHT}
      width="100%"
    >
      {Row}
    </List>
  );
};

// 对比：不用虚拟滚动，10万行 = 10万个 DOM 节点 → 页面卡死
// 用虚拟滚动，10万行 = ~20 个可见 DOM 节点 → 流畅滚动
```

## 6. Azure Data Copy 业务场景实战

### 大数据表格优化方案

```typescript
// 场景：展示数百万条数据复制记录
// 挑战：表格数据量大、实时更新、导出功能

interface CopyJobRecord {
  id: string;
  sourcePath: string;
  destPath: string;
  status: 'running' | 'success' | 'failed';
  bytesTransferred: number;
  updatedAt: Date;
}

// 方案1：分页 + 虚拟滚动（每页 1000 条，只渲染可见行）
const usePaginatedData = (pageSize = 1000) => {
  const [page, setPage] = useState(0);
  const [data, setData] = useState<CopyJobRecord[]>([]);

  const { data: pageData } = useQuery({
    queryKey: ['copy-jobs', page],
    queryFn: () => fetchCopyJobs({ offset: page * pageSize, limit: pageSize }),
    keepPreviousData: true, // 翻页时保留旧数据，避免闪烁
  });

  return { data: pageData ?? [], page, setPage };
};

// 方案2：Web Worker 处理数据统计
// main thread: UI 渲染
// worker: 计算总字节数、成功率等聚合指标

// 方案3：防抖搜索 + AbortController 取消过期请求
const useSearch = (query: string) => {
  const abortRef = useRef<AbortController>();

  const debouncedSearch = useMemo(
    () => debounce(async (q: string) => {
      abortRef.current?.abort();
      abortRef.current = new AbortController();
      const results = await searchCopyJobs(q, { signal: abortRef.current.signal });
      return results;
    }, 300),
    []
  );

  return debouncedSearch(query);
};
```
