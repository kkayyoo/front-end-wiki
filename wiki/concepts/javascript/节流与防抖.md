# 节流（Throttle）与防抖（Debounce）

## 定义

**防抖（Debounce）**：多次触发只执行最后一次。触发后等待 n 毫秒，若期间再次触发则重新计时，直到 n 毫秒内无再次触发才执行。

**节流（Throttle）**：规定时间内只执行一次，无论触发多少次。

## 使用场景

| 场景 | 选择 | 原因 |
|---|---|---|
| 搜索框输入联想 | 防抖 | 等用户停止输入后再发请求 |
| 表单重复提交 | 防抖 | 只提交最后一次 |
| 窗口 resize 重绘 | 防抖 | 等 resize 结束后执行一次 |
| 滚动加载更多 | 节流 | 限制频率，但保证每隔一段时间都执行 |
| 高频点击按钮 | 节流 | 固定频率响应 |
| 拖拽事件 | 节流 | 限制渲染频率 |

## 实现

```typescript
// 防抖（Debounce）
function debounce<T extends (...args: any[]) => any>(fn: T, delay: number) {
  let timer: ReturnType<typeof setTimeout> | null = null;
  return function (this: unknown, ...args: Parameters<T>) {
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
      timer = null;
    }, delay);
  };
}

// 节流（Throttle）—— 时间戳版
function throttle<T extends (...args: any[]) => any>(fn: T, delay: number) {
  let lastTime = 0;
  return function (this: unknown, ...args: Parameters<T>) {
    const now = Date.now();
    if (now - lastTime > delay) {
      fn.apply(this, args);
      lastTime = now;
    }
  };
}
```

## 实际使用（Angular + RxJS）

在 Angular 项目中，防抖/节流更常用 RxJS 操作符：

```typescript
import { debounceTime, throttleTime } from 'rxjs/operators';

// 搜索框防抖（Azure Data 场景：搜索数据源）
searchControl.valueChanges.pipe(
  debounceTime(300),
  distinctUntilChanged()
).subscribe(query => this.searchDataSources(query));

// 滚动节流
fromEvent(window, 'scroll').pipe(
  throttleTime(200)
).subscribe(() => this.checkScrollPosition());
```

## 面试高频题

**Q: 防抖和节流的本质区别？**

> - 防抖：**合并**多次触发为一次（最后一次生效）
> - 节流：**稀释**触发频率（每隔 n 毫秒最多执行一次）
> - 口诀：防抖防的是"最后一次"，节流控制的是"执行频率"

**Q: 如何实现一个带立即执行的防抖？**

```typescript
function debounce(fn: Function, delay: number, immediate = false) {
  let timer: any = null;
  return function (...args: any[]) {
    if (immediate && !timer) {
      fn.apply(this, args); // 立即执行第一次
    }
    clearTimeout(timer);
    timer = setTimeout(() => {
      if (!immediate) fn.apply(this, args);
      timer = null;
    }, delay);
  };
}
```
