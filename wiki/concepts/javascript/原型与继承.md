# 原型与继承

## 核心关系

```
构造函数.prototype ←→ 实例.__proto__（相等）
构造函数.prototype.constructor === 构造函数
```

```js
function Person(name) {
  this.name = name;
}
const p = new Person('张三');

p.__proto__ === Person.prototype        // true
Person.prototype.constructor === Person // true
p instanceof Person                     // true
```

## 原型链

访问属性时，JS 沿原型链向上查找，直到 `null`：

```
p → Person.prototype → Object.prototype → null
```

```js
Person.prototype.greet = function() {
  return `Hello, ${this.name}`;
};
p.greet(); // 'Hello, 张三'（从原型上找到）
```

## new 做了什么？

```js
// 手写 new
function myNew(Constructor, ...args) {
  // 1. 创建空对象，原型指向 Constructor.prototype
  const obj = Object.create(Constructor.prototype);
  // 2. 执行构造函数，绑定 this
  const result = Constructor.apply(obj, args);
  // 3. 若构造函数返回对象，用那个；否则返回 obj
  return result instanceof Object ? result : obj;
}
```

## 继承方式对比

| 方式 | 优点 | 缺点 |
|------|------|------|
| 原型链继承 | 简单 | 引用类型共享，无法传参 |
| 构造函数继承 | 独立属性，可传参 | 方法不共享，内存浪费 |
| 组合继承 | 兼顾属性和方法 | 调用两次父构造函数 |
| 寄生组合式继承 | 最优（ES5） | 写法稍复杂 |
| ES6 class | 语法简洁，语义清晰 | 需转译兼容旧浏览器 |

### 寄生组合式继承（ES5 最佳方案）

```js
function Animal(name) {
  this.name = name;
}
Animal.prototype.speak = function() {
  return `${this.name} speaks`;
};

function Dog(name, breed) {
  Animal.call(this, name);    // 继承实例属性
  this.breed = breed;
}
// 继承原型方法（不调用 Animal 构造函数！）
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;  // 修复 constructor 指向

const d = new Dog('旺财', '柴犬');
d.speak(); // '旺财 speaks'
```

### ES6 class 继承（推荐）

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    return `${this.name} speaks`;
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name); // 必须先调用 super，否则 this 未初始化
    this.breed = breed;
  }
  bark() {
    return `${this.name}: Woof!`;
  }
}

const d = new Dog('旺财', '柴犬');
d.speak(); // '旺财 speaks'
d.bark();  // '旺财: Woof!'
```

> **实际开发**：ES6 class 本质是语法糖，底层仍是原型链。`class` 声明不会提升（Temporal Dead Zone），`function` 声明会提升。

## 面试高频题

**Q: `__proto__` 和 `prototype` 的区别？**
> - `prototype`：函数才有的属性，指向该函数的原型对象
> - `__proto__`：每个对象都有，指向创建该对象的构造函数的 `prototype`
> - 推荐用 `Object.getPrototypeOf(obj)` 代替 `obj.__proto__`（`__proto__` 非标准）

**Q: Object.create() 和 new 的区别？**
```js
// Object.create(proto)：创建对象，原型指定为 proto
const obj1 = Object.create(Animal.prototype);
// obj1.__proto__ === Animal.prototype，但未执行构造函数

// new Animal()：执行构造函数 + 原型链设置
const obj2 = new Animal('test');
```

**Q: 如何判断属性是自身属性还是原型属性？**
```js
const p = new Person('张三');
p.hasOwnProperty('name')  // true（自身属性）
p.hasOwnProperty('greet') // false（原型属性）

// for...in 会遍历原型链属性，加 hasOwnProperty 过滤
for (const key in p) {
  if (p.hasOwnProperty(key)) {
    console.log(key); // 只输出自身属性
  }
}
// 或用 Object.keys(p) — 只返回自身可枚举属性
```
