# 数组去重的 6 种实现方法

> 从 O(n²) 到 O(n) 的进化之路，理解每种方案的时间/空间复杂度权衡。

## 参数校验模板（所有方法共用）

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) {
    console.log('type error');
    return [];
  }
  // ...具体逻辑
}
```

## 方法一：双重循环（暴力法）O(n²)

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  let res = [arr[0]];
  for (let i = 1; i < arr.length; i++) {
    let flag = true;
    for (let j = 0; j < res.length; j++) {
      if (arr[i] === res[j]) { flag = false; break; }
    }
    if (flag) res.push(arr[i]);
  }
  return res;
}
```

- **时间**：O(n²) — 外层 n 次，内层最多 n 次
- **空间**：O(n)
- 适合：理解基本原理，不适合生产

## 方法二：indexOf O(n²)

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  const res = [];
  for (let i = 0; i < arr.length; i++) {
    if (res.indexOf(arr[i]) === -1) res.push(arr[i]);
  }
  return res;
}
```

- **时间**：O(n²) — indexOf 内部也是 O(n) 遍历
- 本质与方法一相同，代码更简洁

## 方法三：filter + indexOf O(n²)

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  return arr.filter((item, index) => index === arr.indexOf(item));
}
```

- 原理：只保留「第一次出现」的元素（index === indexOf 的结果）
- **时间**：O(n²)，函数式风格最简洁，但性能未改善

## 方法四：排序后相邻比较 O(nlogn)

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  arr = arr.slice().sort((a, b) => a - b); // 数字数组必须传比较函数！
  let res = [arr[0]];
  for (let i = 1; i < arr.length; i++) {
    if (arr[i] !== arr[i - 1]) res.push(arr[i]);
  }
  return res;
}
```

- **时间**：O(nlogn) — sort O(nlogn) + 遍历 O(n)
- ⚠️ `sort()` 默认按字符串排序，数字必须传 `(a, b) => a - b`
- ⚠️ 会改变原数组元素顺序（若需保序，不适用）

## 方法五：对象字面量 / HashMap O(n)

```javascript
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  const res = [];
  const obj = {};
  for (let i = 0; i < arr.length; i++) {
    // ✅ 用 hasOwnProperty 而非 !obj[arr[i]]
    // 原因：值为 0/false/'' 时，!obj[arr[i]] 会误判
    if (!obj.hasOwnProperty(arr[i])) {
      res.push(arr[i]);
      obj[arr[i]] = 1;
    }
  }
  return res;
}
```

- **时间**：O(n) — 对象属性查找 O(1)，只遍历一次
- **空间**：O(n)（结果数组 + HashMap 对象）
- 经典「空间换时间」
- ⚠️ 元素为对象时需 `JSON.stringify(arr[i])` 作 key

## 方法六：ES6 Set（推荐）O(n)

```javascript
// 完整版
function unique(arr) {
  if (!Array.isArray(arr)) return [];
  return [...new Set(arr)];
}

// 一行版（生产环境）
const unique = arr => [...new Set(arr)];
```

- **时间**：O(n) — Set 内部是 HashMap 实现
- **空间**：O(n)
- 🎯 生产环境首选：简洁、高效、语义清晰

## 六种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 核心思路 |
|---|---|---|---|
| ① 双重循环 | O(n²) | O(n) | 暴力枚举 |
| ② indexOf | O(n²) | O(n) | API 替代内层循环 |
| ③ filter+indexOf | O(n²) | O(n) | 函数式风格 |
| ④ 排序+相邻比较 | O(nlogn) | O(n) | 先排序降低比较次数 |
| ⑤ 对象/HashMap | O(n) | O(n) | 空间换时间 |
| ⑥ ES6 Set | O(n) | O(n) | Set 天生去重 |

## 直观感受（n = 10000）

```
O(n²)    → 100,000,000 次操作 😱
O(nlogn) →     132,877 次操作 😊
O(n)     →      10,000 次操作 🚀
```

## 场景选择

| 场景 | 推荐 | 原因 |
|---|---|---|
| 生产环境 | ⑥ Set | 简洁、高效、现代 |
| 面试手写 | ⑤ HashMap | 展示算法思维+复杂度理解 |
| 兼容旧浏览器 | ④⑤ | 不依赖 ES6 |
| 大数据量 | ④⑤⑥ | 避免 O(n²) |

## 面试高频题

**Q: 手写一个 O(n) 的数组去重，并说明原理**

```typescript
// 面试标准答案：HashMap 方案（展示算法思维）
function unique<T>(arr: T[]): T[] {
  if (!Array.isArray(arr)) return [];
  const seen = new Map<string, boolean>();
  return arr.filter(item => {
    const key = JSON.stringify(item); // 支持对象元素
    if (seen.has(key)) return false;
    seen.set(key, true);
    return true;
  });
}
// 时间 O(n)，空间 O(n)，用 Map 替代对象，支持任意类型的 key
```

> **实际项目场景（Azure Data Copy）**：处理大量数据源列表去重时，用 Set 或 Map，避免 O(n²) 在数据量大时导致页面卡顿。

**Q: `[...new Set(arr)]` 能处理对象去重吗？**

> 不能。Set 用引用相等（`===`）判断，两个内容相同的对象引用不同，不会被去重。对象去重需要用 `JSON.stringify` 作 key 的 HashMap 方案。

```javascript
const arr = [{a:1}, {a:1}];
[...new Set(arr)].length // 2 ❌ 未去重

// ✅ 对象去重
const unique = arr => {
  const seen = new Set();
  return arr.filter(item => {
    const key = JSON.stringify(item);
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
};
```
